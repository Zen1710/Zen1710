## Projects

### Whitefly Detector

Detects and counts whiteflies on gourd-family plants right in the browser, from a webcam or an uploaded photo, then rates the infestation risk. Built with YOLO11n, TensorFlow.js, Python, and JavaScript.

[![Live demo](https://img.shields.io/badge/Live%20demo-0A78B4?style=for-the-badge)](https://zen1710.github.io/YOLOv11_detectionWhiteFlies/)
[![Repository](https://img.shields.io/badge/Repository-121416?style=for-the-badge&logo=github&logoColor=1FB5E9)](https://github.com/Zen1710/YOLOv11_detectionWhiteFlies)

### Personal Portfolio

A Next.js portfolio whose content lives in MDX files, with Draft and Published entries and a server-side contact form. Built with Next.js 16, TypeScript, Tailwind CSS v4, and MDX. In development.

[![Repository](https://img.shields.io/badge/Repository-121416?style=for-the-badge&logo=github&logoColor=1FB5E9)](https://github.com/Zen1710/Porto)

### Gather

A Discord-like chat app in a pnpm monorepo, with guilds, channels, messages, invites, and presence on the way. Built with React, Hono, Socket.IO, Drizzle, and PostgreSQL. In development; the repository is private.

### Smartphone Catalog

A phone catalog with search, brand filters, sorting, a detail view, and side-by-side comparison of up to three phones. Built with plain HTML, CSS, and JavaScript.
